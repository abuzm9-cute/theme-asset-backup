# 美化素材备份器（SillyTavern UI Extension）V0.2.1

## 安装方式
1. 将本仓库放入 GitHub，仓库根目录必须直接包含 `manifest.json`、`index.js`、`style.css`。
2. 在 SillyTavern：扩展 → 安装扩展，粘贴仓库地址。
3. 安装完成后刷新酒馆，在扩展设置中找到「美化素材备份器」。

## 使用方式
1. 选择一个你主动指定的美化 JSON 文件。
2. 工具扫描 JSON 字符串中的 `url(https://...)` 图片链接并按 URL 去重。
3. 检查用途和文件名，可手动修改文件名。
4. 选择图片并下载 ZIP。ZIP 内包含图片和 `素材清单.json`。

## 重要限制
- 这是纯浏览器端 UI 扩展，不需要启用 Server Plugins，不需要修改 config.yaml。
- 不会主动上传所选 JSON 文件。
- 浏览器的 CORS 规则可能阻止读取部分图床图片。此类图片无法被本扩展打包；可点「打开原图」后使用浏览器自身的保存功能。
- 用途识别依据 JSON 中的字段路径和 CSS 字符串片段，是启发式判断，可能不准确。请在下载前检查。
- 当前版本只扫描 JSON 文本中可识别的 `url(https://...)` 图片地址；不处理字体，不解析运行时动态生成的 CSS。
- 图片预览目前以下载读取为主；若图床不允许跨域读取，可能无法显示预览。
- 请尊重素材作者的使用声明，不要传播或商用未经授权的素材。

## 安全
- 仅在用户选择文件后读取该文件。
- 只向图片 URL 发起浏览器 fetch 请求，不上传聊天记录或 JSON。
- 扩展本身没有服务器端代码，也不请求额外账号权限。
