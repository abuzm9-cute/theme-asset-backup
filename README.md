# 美化素材扫描器＋备份器 0.3.0

这是 SillyTavern 的纯 UI 扩展，不需要 Server Plugins、不需要修改 `config.yaml`，也不需要额外文件系统权限。

## 功能

1. 用户主动选择一份美化 JSON，插件只扫描该文件中的 CSS `url(...)` 图片链接。
2. 展示图片预览、URL 原始文件名和完整 URL。
3. 点击「查看 CSS 位置」可查看 JSON 字段路径、CSS 字符串中的行号/列号，以及目标行前后各两行代码。
4. 完全相同的 URL 合并为一张图片卡片，但会保留它在 CSS 中的全部引用位置；不同 URL 不会按图片内容合并。
5. 可勾选图片并打包 ZIP。ZIP 内保留 URL 文件名，并附带 `素材清单.json`，记录保存文件名、完整 URL 和所有 CSS 引用位置。
6. 图片预览失败或批量读取受跨域限制时，可尝试「打开原图」并由浏览器手动保存。

## 安装/更新

保留原来的仓库 `https://github.com/abuzm9-cute/theme-asset-backup`。将本目录中的 `index.js`、`style.css`、`manifest.json`、`README.md` 分别更新到仓库根目录（与原来的四个文件同一层）。在 SillyTavern 扩展管理中更新扩展，然后刷新页面。

## 限制与隐私

- 仅扫描用户主动选择的 JSON，不会自动扫描所有主题，也不会上传 JSON。
- 只提取 CSS `url(...)` 中的 HTTP/HTTPS 资源；@import 样式表链接和常见字体文件扩展名（woff/woff2/ttf/otf/eot）会跳过。
- 行号是对应 JSON 字段内 CSS 文本的行号，不是整个 JSON 文件的物理行号。
- `<img>` 预览通常不受 CORS 读取限制，但能否显示仍取决于图床是否允许浏览器加载图片。
- ZIP 批量备份需要图床允许跨域 fetch。若图床拒绝跨域读取，插件不能绕过限制；请尝试打开原图并手动保存。
- 不修改原始 JSON/CSS，不替换作者链接，不备份字体。
- 请遵守素材作者的授权和使用声明。
